## Environment

- Architecture: Apple Silicon (`aarch64`)
- Rust toolchains: `rustc 1.94.1` and the declared minimum `rustc 1.88.0`
- Network binding used by the runtime smoke test: loopback only

## Automated checks

The following commands passed on the current stable toolchain and were repeated successfully with `cargo +1.88.0`:

~~~bash
cargo fmt --check
cargo check --locked --all-targets
cargo clippy --locked --all-targets -- -D warnings
cargo test --locked
cargo bench --locked --no-run
~~~

Test totals were 42 library tests, 44 binary tests, and 13 integration tests. Benchmark targets compiled; this validation did not publish benchmark timing results.

## Runtime checks

- `cargo run --locked -- --help` displayed the documented command surface.
- `cargo run --locked -- version` returned the package version.
- An agent bound to a temporary loopback port returned `ok` from `/health` and a live JSON `StatsSnapshot` from `/metrics`.
- Ctrl-C stopped the agent through its graceful-shutdown path.
- Local JSON and CSV exports completed and contained live host metrics.

The HTTP response and exported host data are deliberately not committed because they change per machine and may contain local process or host information.

## Boundaries

The smoke test did not expose the agent outside loopback, test authentication or TLS (neither is implemented), validate process termination, or establish a Windows/Linux runtime result. Linux is independently exercised by the repository CI workflow.
